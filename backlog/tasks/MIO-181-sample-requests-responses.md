## Goal

Deliverable "sample requests and responses".

## Scope

- `docs/samples/*.http` for each of the 8 steps, for Casino A and Casino B, plus the Part C cases
  (duplicate, concurrent, timeout, failure, unauthorized).
- Recorded responses next to each request, generated by running the demo, not written by hand.

## Acceptance criteria

- A script replays every sample against a running stack and compares responses with the recorded ones
  (ignoring ids and timestamps); it runs in CI.
- Signatures in the samples are computed by a helper, so the samples stay valid when keys change.
