## Goal

Nothing private reaches the public repository: not in files, not in generated artifacts, not in commit
history, not in raw AI output. The repository is public, so this is a gate: no push to a public remote
happens before this task is done, and every later push passes it.

## Scope

- **Private inspection, run before every push to a public remote.** The inspection tool and its
  denylist (names, handles, hosts, paths and other identifiers that must not appear) live in the
  maintainer's private workspace, outside this repository; the denylist is never committed, not even
  hashed. The tool inspects:
  - every tracked file, including `README`, `LICENSE`, `docs/**` and generated ADRs and configuration;
  - `prompts/**`, `.claude/**`, `docs/ai/**` and any evidence folder;
  - file names and paths;
  - every commit in the history to be pushed: message, trailers, author and committer names and emails;
  - metadata of images and documents (text chunks, EXIF, PDF properties);
  - the content of tags and release notes.
- **In-repo generic check** (safe to publish because it names nothing private): fails CI on absolute
  home-directory paths, private IP ranges, email addresses other than the allowed no-reply addresses,
  and secret-like strings.
- **Sanitized export of AI artifacts.** Raw prompts, transcripts and evaluation outputs are never committed.
  An export step produces sanitized copies (paths and identifiers replaced by neutral placeholders), and
  the private inspection runs again on the exported copies before they are added.
- **Allowed mentions** are listed in the repository (the public list approved by the owner); everything
  not on it is reviewed by a person before the first publication.

## Acceptance criteria

- **Negative fixtures:** a throwaway fixture repository (generated by the private tool, never pushed)
  plants one denylisted value in each location above: file content, file name, commit message, commit
  trailer, author email, image metadata, PDF metadata, tag message, an exported AI transcript. The
  inspection reports every one of them with its location; a clean fixture passes.
- Removing any one location from the inspection makes the matching fixture go undetected (the reviewer
  re-applies this as a mutation and records the red run).
- The in-repo generic check fails on a planted home-directory path and a planted non-allowed email.
- The first public push happens only after a recorded clean run over the full history; the run record
  (date, commit range, result, no denylist contents) is kept in the maintainer's private notes.
- The inspection covers images and the AI evidence folder from its first run, so later screenshots and
  evidence pass through it before they are committed.
