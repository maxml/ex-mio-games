# EPIC-12 Design and design system

## Goal

Design drives money, so it comes before code. A clickable prototype of the main screens for players,
operators and the platform admin is built first in `design/prototype/`. The whole frontend is then
composed from Storybook components; no screen uses ad-hoc markup outside the component library.
