# Known gaps: web calls without a service endpoint

The web BFF (`apps/web/app/api/[...path]/route.ts`, logic in `apps/web/src/layers/shared/api/bff/`) calls the
services through the reconciled contracts. Where no service has an endpoint, the browser adapter
(`createHybridApi`, `NEXT_PUBLIC_MIO_API=http`) keeps the mock adapter **for that call only**. A failed real call
is never replaced by the mock. The list of mock-answered calls is `GAP_CALLS` in
`apps/web/src/layers/shared/api/mio/hybrid.ts`; this table is its documentation.

## Not gaps (the call exists and is wired)

Spin (`POST /v1/spins`, `segment_index/segment_label/reward_coins`), `GET /v1/me/spins`, balance
(`GET /v1/me/balance`, `available`), redemption (`POST /v1/redemptions` 202, 409 `insufficient_funds`, store status
words), store items, operator signup, plans, payment attempt and cancel (with `Idempotency-Key`), usage, invoices,
acting (`POST /v1/auth/acting`, token kept server-side), audit trail.
