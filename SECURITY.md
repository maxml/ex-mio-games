# Security Policy

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Instead, email the maintainer at `<security-contact@example.com>`. Include:

- A description of the issue and the impact.
- Steps to reproduce.
- The version, branch, or commit that is affected.

You can expect an initial acknowledgement within 7 days. We will work on a
fix and coordinate disclosure with you.

> The contact above is a placeholder. `pnpm run setup` replaces it with the
> email you provide; set it manually before publishing if you skip setup.

## Supported versions

This project is a template; security fixes are applied on `main` only.
